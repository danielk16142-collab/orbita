# Compliance pack (internal)

Working drafts. **Not legal advice: have a lawyer review before launch.** Public documents live in `apps/web/content/legal/` and are served at `/{locale}/legal/{doc}`.

| File | Purpose |
|---|---|
| `data-map.md` | What personal data we hold, where, why, who can access it |
| `rights-requests.md` | Procedure for access/export/correction/deletion requests (30-day clock) |
| `incident-response.md` | Confidentiality-incident procedure and notification duties |
| `launch-checklist.md` | What must be done before going live and before platform app review |

## Frameworks covered
- **Quebec Law 25** (private sector privacy act): privacy officer, privacy impact assessments, incident register, transfer assessments outside Quebec, consent, rights, French-language availability.
- **PIPEDA** (Canada, federal).
- **GDPR / UK GDPR** if EU/UK users or audiences are in scope: lawful basis, DPA, SCCs, 72-hour breach notice, records of processing.
- **CCPA/CPRA** if California residents are in scope: notice, no sale/sharing, rights, 45-day response (we use 30).
- **Platform policies**: Meta Platform Terms, TikTok developer terms, LinkedIn and Google/YouTube API terms (data use limits, deletion callbacks, privacy policy URL).
